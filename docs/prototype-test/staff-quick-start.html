Staff quick-start

A short guide for the CareTrack prototype training session

Demo data only. Use the training environment and made-up aliases. Do not enter real patient details. This prototype does not replace local care-team procedures.

1. Create an episode

  1. Open /staff in the training site and choose New episode.
  2. Enter a demo alias, choose the procedure, and enter a demo ward or bed. Select Create episode.
  3. Check the details and the family link on the confirmation screen.

2. Advance a stage

  1. Return to the staff list and find the demo episode.
  2. Choose the button labelled with the next stage. The stage changes once; the page shows an Undo option briefly if you tapped by mistake.
  3. Check the new stage on the card. Do not advance to make the screen look busy; update only when the scenario calls for it.

3. Flag a delay

  1. Open the episode’s status menu and choose Mark delayed.
  2. Choose the closest training reason if asked. The family page uses approved, calm wording, not the reason entered for staff.
  3. When the scenario ends, clear the flag from the same menu.

4. Share the family link

  1. Use Copy family link or the approved sharing option.
  2. For this session, share only with the role-play family member or facilitator. The link code grants access; treat it as private.
  3. Ask them to open it and describe what they understand. Never add personal information to the link or messages.

If anything is unclear: pause the exercise and tell the facilitator. In the prototype, unknown or unexplained family status should say, “Please call the care team.”
